# 성당 관리 시스템 (Church Management System)

⛪ 신자와 관리자를 위한 현대적인 성당 관리 시스템

## 📱 주요 기능

### 신자용 앱
- 📖 주보 확인
- 📢 공지사항
- ⏰ 미사 시간 안내
- 🎉 행사 등록
- 💰 온라인 헌금

### 관리자 대시보드
- 👥 신자 관리
- 📝 주보/공지사항 작성
- 📅 행사 관리
- 💬 메시지 발송
- 📊 통계 및 보고서

## 🚀 기술 스택

- **Frontend**: React + Vite
- **Backend**: Supabase
- **Hosting**: Vercel
- **Storage**: Cloudinary
- **Styling**: CSS Modules

## 🛠️ 설치 및 실행

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build
```

## 📝 환경 변수

`.env.local` 파일을 생성하고 다음 변수를 설정하세요:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_CLOUDINARY_CLOUD_NAME=your_cloudinary_name
```
