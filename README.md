# 성당 관리 시스템

⛪ 현대적인 성당 관리 및 신자 소통 플랫폼

## 🌟 주요 기능

### 신자용
- 📖 주보 보기 (PDF/이미지)
- 📢 공지사항 확인
- ⏰ 미사 시간표
- 🔐 회원가입 및 로그인

### 관리자용
- 📊 대시보드
- 📢 공지사항 관리 (이미지 포함)
- 📖 주보 업로드
- 👥 회원 관리

## 🚀 배포

- **Production**: https://sore-gamma.vercel.app
- **Framework**: React + Vite
- **Hosting**: Vercel
- **Database**: Supabase
- **Storage**: Cloudinary

## 🛠 기술 스택

- React 18
- Vite
- Supabase (Auth + Database)
- Cloudinary (Image/File Upload)
- CSS Modules
